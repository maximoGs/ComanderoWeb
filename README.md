# Los Bocheros Restó · Lamadrid Estate Wines

Menú digital e interactivo de **7 Pasos** para el restaurante **Los Bocheros Restó** de la bodega **Lamadrid Estate Wines**, ubicada en **Las Compuertas, Luján de Cuyo, Mendoza, Argentina**.

Diseñado bajo una estética **fina, argentina, suave y delicadamente rústica**, enalteciendo el terruño mendocino, las viñas centenarias y la gastronomía de raíces.

---

## 🍇 Características del Menú

- **Diseño Rústico & Fino**: Paleta de tonos papel pergamino, oro viejo, azul emblemático de Lamadrid y acentos terruño/vino.
- **Identidad de Marca**: Integración del imagotipo oficial de *Lamadrid Estate Wines* con marco refinado.
- **Menú de 7 Pasos Completo**:
  1. **Primer Paso**: Queso de cabra · Chutney · Hierbas
  2. **Segundo Paso**: Gírgola · Calabaza · Nueces
  3. **Tercer Paso**: Molleja · Coliflor · Manzana · AOVE Lamadrid
  4. **Cuarto Paso**: Empanada Los Bocheros *(Especialidad del Chef)*
  5. **Quinto Paso**: Ojo de Bife *(Principal con maridaje ícono Matilde Malbec)*
  6. **Sexto Paso**: Yogurt · Limón *(Pre-postre limpiador de paladar)*
  7. **Séptimo Paso**: Chocolate · Pomelo · Toffee · AOVE Lamadrid
- **Doble Modalidad de Visualización**:
  - **Carta Completa**: Formato tradicional de alta enogastronomía.
  - **Paso a Paso Interactivo**: Despliegue guiado curso por curso con selector de pasos y notas de cata.
- **Filtro de Maridajes**: Alterna entre *Todos los Maridajes*, *Clásico (Reserva)* y *Upgrade (Gran Reserva & Íconos)*.
- **Bilingüe (Español / Inglés)**: Adaptado para enoturistas internacionales con traducción completa e instantánea.
- **Optimizado para Impresión (`@media print`)**: Listo para imprimir en formato físico de restaurante sin elementos de navegación.
- **Reserva Directa por WhatsApp**: Enlace preconfigurado para contacto inmediato con el equipo de turismo.

## 🚀 Visualización Local

Puedes abrir directamente el archivo `index.html` en cualquier navegador web moderno o servirlo localmente:

```bash
# Con Node.js
npx serve .

# O con Python
python -m http.server 8080
```
